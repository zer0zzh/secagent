# 阶段1 · 01 需求与范围

> 场景：**授权靶场内的 Web 漏洞自动化验证智能体**
> 纪律：本文件写完并确认后，才允许动代码。改需求先改这里。
> 日期：2026-11-05

## 三个问题

### 给谁用

| 角色 | 场景 | 最在意什么 |
|---|---|---|
| 我（学生 / 开发者） | 11-06~08 培训现场做成果展示与备赛 | 5 分钟内能演示、能被追问、数字能复现 |
| 主讲老师 / 主办方 | 评估"这学校能不能独立出成果"、判断能不能转成教学案例 | 有证据链、有评测数据、能直接拿进课堂 |
| 御网杯备赛队员 | 拿这套东西做新赛道训练 | 靶场上跑得稳、结论不骗人 |

### 解决什么问题

**核心问题**：现在的安全智能体 Demo 靠模型自评下结论，"flag 看起来对"和"flag 验证过是对的"混在一起。
我们要在授权靶场里，把"模型的判断"变成"挂了可复现证据的结论"，并且用一组含负例的评测集，
量出**误报率**这个别人拿不出来的数字。

一句话：**不是做一个会做题的 Agent，而是做一个知道自己错在哪的 Agent。**

### 绝对不做什么（写死，防止范围膨胀）

1. 不碰公网目标、不碰未授权资产 —— allowlist 只允许 `127.0.0.1` / 私网 / `*.local`。
2. 不做自动利用链、不做反弹 shell、不做写操作自动化 —— 只做"探测 + 验证"，不执行破坏。
3. 不让模型自评当结论 —— 任何 `verdict` 必须挂至少 1 条 `evidence`，且经过独立 verifier。
4. 不做前端 / 不做登录 / 不做用户系统 / 不做微服务 / 不做云部署。
5. 不做多智能体、不做 RAG、不做模型微调 —— 这些是培训之后的事。
6. 不为了"看起来强"伪造评测数字，靶场跑出多少就是多少。

## 核心功能清单（按优先级）

| 优先级 | 功能 | 为什么必须是这个顺序 |
|---|---|---|
| **P0-1** | 工具层扩到 4 个：`http_probe` / `port_scan` / `dir_enum` / `payload_verify` | 没有 `payload_verify` 就没有"验证"，整个场景不成立 |
| **P0-2** | 证据链落库：每次工具调用、每条观测、每个结论都结构化存下来 | 展示时"指哪打哪"，也是复盘误判的唯一依据 |
| **P0-3** | 独立 verifier：三类断言（响应差异 / 报错回显 / 时间盲注阈值） | 分水岭；没有它，阶段1 只是又一个 Demo |
| **P0-4** | 评测集 12 题（正 6 / 负 6）+ 一键出报告（成功率、误报率、步数、耗时、token） | 培训模块 9/10 需要的"真实数字" |
| **P0-5** | 一键 Demo + trace + 报告落盘 | 现场防翻车 |
| P1 | 人工审批节点（human-in-the-loop）、HTML 报告、`--resume` 续跑 | 现场有余力再加 |
| P2 | 网页看板、跨校协作、多智能体、bge-m3 RAG | 培训之后再排 |

## 用户故事

1. 作为**参赛队员**，我希望给 Agent 一个靶场 URL，它返回"疑似注入点 + payload + 三次实际响应差异 + 置信度"，这样我能判断该不该信它。
2. 作为**主讲老师**，我希望每个结论都能点开看到是哪条工具返回、哪条断言支撑的，这样我能判断学生是真懂还是调了个模型。
3. 作为**备赛队员**，我希望在静态 200 页、WAF 拦截页、蜜罐诱导页上跑一遍，看到 Agent 在哪里被骗、被哪条断言拦下。
4. 作为**主办方**，我希望拿到一份 12 题评测报告（含误报率），能直接判断这套东西是不是可复用的实训脚本。
5. 作为**开发者**，我希望每次运行都有 trace 和数据库记录，出问题时能回到具体某一步看当时的完整输入输出。

## 验收标准（阶段1 做完的判定）

| 项 | 通过线 |
|---|---|
| 端到端 | 一条命令在 DVWA / 本地靶场上跑完"探测 → 验证 → 结论" |
| 证据链 | 每个 verdict 至少挂 1 条可复现 evidence，DB 里查得到 |
| 负例 | 6 个负例里至少能讲清 3 个失败模式（附 trace 片段） |
| 误报率 | 有真实数字；目标 ≤15%，高于也如实写进报告 |
| 可复现 | 换台机器按 README 三步能跑出同样的表 |
| 时长 | 单次演示 ≤90 秒 |

## 明确排除在本阶段之外

- 真实漏洞利用、提权、横向移动
- 任何需要联网调用云端大模型才能演示的路径（现场网络不可控）
- 用 Docker 起完整 DVWA 作为**前置依赖**（先做到不依赖 Docker 也能跑通）
